# Results

- `event/` — sequence identities, exact TSD, current transcript models,
  mm39→rn7 liftOver summary and validation JSON.
- `synteny/` — feature mappings, locus quality control, presence/absence calls,
  TSD/empty-site comparisons, extracted FASTA sequences, pairwise alignments,
  dating summary and run manifest.
- `expression/` — CAGE, RSEM, exact junction, long-read, ORF and Ribo-seq
  tables derived from accessioned public datasets.
- `validation_report.tsv` — generated by the final cross-module audit.

These are machine-readable analysis outputs. Manuscript figure source tables
are not maintained separately in this package.
