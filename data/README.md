# Data

Only inputs needed by the analyses are retained.

- `event/` contains the focal GRCm39 source interval, the relevant
  `Dnaaf6`/`Dnaaf6rt` transcript and protein records, the current Ensembl
  `Alyreffm1` lookup response, and archived mm39→rn7 liftOver records. The
  recipient sequence is reused from the mouse locus in `synteny/loci/`.
- `synteny/` contains the two configuration tables, nine accession-versioned
  orthologous loci and their retrieval metadata.
- `expression/` contains compact annotation/reference inputs and the reduced
  FANTOM5 matrix. Large public expression inputs are downloaded only for the
  optional full workflow.

Files generated by the analyses belong in `results/`, not here. Source URLs,
accessions, assemblies and hashes are documented in
`../docs/DATA_PROVENANCE.md`.
