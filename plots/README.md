# Diagnostic plots

The PNG files in this directory are analysis/QC views used to inspect the
evidence. They are regenerated by `scripts/run_all.sh` and are intentionally
separate from the manuscript artwork.

- `event/` — focal event reconstruction and current transcript-model audit.
- `synteny/` — orthologous-site size/state check and presence/absence tree.
- `expression/` — CAGE/RNA-seq/RSEM/Ribo-seq summary and transcript-level
  evidence map.

No PowerPoint, SVG layout source, caption file or manuscript panel builder is
included.
