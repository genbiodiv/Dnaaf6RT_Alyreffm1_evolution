# Interpretation limits

The strongest conclusion is a physical RNA-mediated insertion that created the
functional retrogene `Dnaaf6rt` and contributed a source-derived 5′ block now
used by several oppositely oriented `Alyreffm1` transcripts.

The following statements are deliberately **not** made:

- The exact historical RNA molecule is known. Sequence homology constrains its
  origin but does not recover the ancestral intermediate.
- A complete functional promoter was necessarily present in, and carried by,
  that RNA. Present-day transcription starts show current regulatory use, not
  the biochemical state of the ancestral source transcript.
- `Alyreffm1` was created de novo as an entirely independent gene by this
  event. Current annotation also contains an insertion-independent promoter,
  and coding isoforms can converge on the same 241-aa CDS.
- The approximately 11-Ma insertion date is the date at which the opposite-
  strand transcript became functional. The phylogenetic bracket dates the DNA
  insertion only.
- `Alyreffm1-202` has been recovered as a complete long-read molecule in
  GSE137490. It has not.
- The 127-aa candidate ORF produces a stable protein. Ribo-seq occupancy is
  compatible with translation but is not definitive protein evidence.

The wording supported by this package is therefore “regulatory and transcript-
architectural innovation associated with retroposition,” not unequivocal
creation of a wholly new opposite-strand gene.
